# T057 · Добавить APKG медиа и повторный импорт

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M3. **Сложность:** L.

## Результат

Включить пакеты Anki в безопасный общий pipeline.

## Зависимости

[T009](T009.md) · [T038](T038.md) · [T051](T051.md) · [T056](T056.md)

## Область изменений

Предлагаемые файлы/модули: `Infrastructure/ImportExport/APKG; Features/Import`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Разобрать media mapping, проверить hashes/UTI, опубликовать через MediaStore.
2. Сохранять external IDs и конфликты local/imported revisions; preview политики дублей.
3. Применять staging атомарно, формировать added/updated/skipped/error report.

## Критерии готовности

- [ ] Повтор одного пакета не размножает внешние записи.
- [ ] Cancel и corrupt media не оставляют наполовину импортированную колоду.

## Проверка

Re-import после локальной правки, missing media и fault injection до commit.
