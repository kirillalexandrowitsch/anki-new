# T001 · Подготовить Xcode и окружение

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M0. **Сложность:** S.

## Результат

Получить воспроизводимое окружение сборки приложения arm64 на macOS 15+.

## Зависимости

Нет; это стартовая задача.

## Область изменений

Предлагаемые файлы/модули: `Окружение и docs`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Проверить наличие полного Xcode и выбрать developer directory; сохранить версию Xcode/Swift/SDK.
2. Зафиксировать deployment target 15.0, язык Swift 6 и arm64; выбрать временный bundle ID без требования платной подписи для локального использования.
3. Описать запуск тестов на минимальной и текущей системе; записать ограничения доступного Mac.

## Критерии готовности

- [ ] xcodebuild -version работает через выбранный Xcode.
- [ ] Документированы toolchain и способ локального запуска без сертификата релиза.

## Проверка

Собрать и запустить временный пустой macOS app target; не изменять пользовательские данные.

## Дизайн-референсы

Инфраструктурная задача без отдельного растрового экрана. Контракт задают [ARCHITECTURE.md](../ARCHITECTURE.md) и [DATA_MODEL.md](../DATA_MODEL.md).

## Ограничения

Выполнять только описанную область. Общие правила сохранения, reveal/ratings и отмены — в [PRODUCT.md](../PRODUCT.md) и [REVIEW_ENGINE.md](../REVIEW_ENGINE.md); файловые операции — в [INTEGRATIONS.md](../INTEGRATIONS.md). Новое поведение документировать до изменения связанных контрактов. Не считать задачу выполненной без её критериев и проверки.
