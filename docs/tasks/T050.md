# T050 · Адаптировать окно и системные панели

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M2. **Сложность:** M.

## Результат

Сохранить работоспособность в компактном окне macOS.

## Зависимости

[T026](T026.md) · [T036](T036.md) · [T039](T039.md) · [T046](T046.md) · [T048](T048.md)

## Область изменений

Предлагаемые файлы/модули: `App/Windows; Infrastructure/Platform/FilePanels`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Скрывать inspector за кнопкой, упрощать второстепенные колонки и сворачивать sidebar.
2. Использовать нативные Open/Save, overwrite confirmation и correct content types.
3. Проверить размеры/скролл диалогов и доступность основной кнопки при увеличенном тексте.

## Критерии готовности

- [ ] На предложенном компактном размере нет обрезанных обязательных действий.
- [ ] Cancel системной панели не создаёт пустой файл и не меняет draft.

## Проверка

Обычное/компактное окно, крупный текст и sandbox file panel smoke.
