# T069 · Завершить системные меню, Справку и About

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M4. **Сложность:** M.

## Результат

Сделать полноценную интеграцию команд в меню macOS.

## Зависимости

[T026](T026.md) · [T047](T047.md) · [T068](T068.md)

## Область изменений

Предлагаемые файлы/модули: `App/Commands; Features/Help`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Заполнить App/File/Edit/View/Window/Help реальными actions и стандартными shortcuts.
2. Добавить About с версией из bundle и локальную Help по занятиям/файлам.
3. Доступность Undo/Redo и Edit-команд определять по активному редактору или session context.

## Критерии готовности

- [ ] Команды меню совпадают с экранными действиями.
- [ ] About не показывает фиктивную версию, Help доступна offline.

## Проверка

Проверить меню в Today, Editor, Study, modal и без активного документа.
