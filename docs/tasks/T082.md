# T082 · Добавить локальную запись произношения

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M4. **Сложность:** L.

## Результат

Записывать и прослушивать себя без автоматической оценки.

## Зависимости

[T009](T009.md) · [T021](T021.md) · [T062](T062.md) · [T081](T081.md)

## Область изменений

Предлагаемые файлы/модули: `Infrastructure/Media/Recording; Features/Editor`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Добавить purpose string, microphone capability и разрешение непосредственно перед записью.
2. Записывать в staging, показывать waveform и воспроизведение своей/референсной записи.
3. Re-record/Delete/Attach имеют явную семантику, Cancel очищает неприменённый файл.

## Критерии готовности

- [ ] Отказ разрешения позволяет вернуться к карточке.
- [ ] Attach создаёт обычный media reference; никаких придуманных accuracy scores.

## Проверка

Allowed/denied mic, interrupted recording, Cancel и повторное воспроизведение offline.
