# T035 · Сделать внутренний центр уведомлений

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** готово. **Этап:** M2. **Сложность:** M.

## Результат

Показывать результаты локальных операций и напоминания внутри приложения.

## Зависимости

[T008](T008.md) · [T011](T011.md) · [T023](T023.md)

## Область изменений

Предлагаемые файлы/модули: `Features/Today/Notifications; Core/UseCases`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Ввести notification kinds, read/unread и ограничение истории сообщений.
2. Публиковать backup success/error только по фактическому результату.
3. Сделать popover с Mark all read и переходом к связанному разделу.

## Критерии готовности

- [ ] Read state сохраняется между запусками.
- [ ] Сообщение о запланированном reminder не утверждает доставку системного баннера.

## Проверка

Пустой/наполненный popover, операция с ошибкой, mark read и reopen.
