# T037 · Добавить Reverse, Cloze и Typed варианты

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M2. **Сложность:** L.

## Результат

Реализовать типы учебных карточек из основного набора.

## Зависимости

[T014](T014.md) · [T015](T015.md) · [T017](T017.md) · [T019](T019.md) · [T036](T036.md)

## Область изменений

Предлагаемые файлы/модули: `Core/Study/Variants; Features/Editor/Study`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Определить стабильные variant keys и генерацию нескольких Cards без смены ID существующих.
2. Показывать обратное направление и cloze скрытие через общую render model.
3. Typed draft раскрывается Показать ответ; сравнение grapheme-aware, оценку пользователь выбирает сам.

## Критерии готовности

- [ ] Каждый вариант имеет независимое расписание.
- [ ] Изменение текста не сбрасывает прогресс; 1–4 не вводят оценку из активного поля.

## Проверка

Многословный ввод, Unicode, добавление/удаление cloze и сохранность existing schedule.
