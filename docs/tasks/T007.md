# T007 · Управлять открытием и блокировкой коллекции

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M0. **Сложность:** M.

## Результат

Создавать одну активную коллекцию с безопасным владением.

## Зависимости

[T006](T006.md)

## Область изменений

Предлагаемые файлы/модули: `App/CollectionCoordinator; Infrastructure/Collections/`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Создать папку контейнера, manifest и registry с UUID.
2. Получать advisory lock до записи, различать занятость процесса и устаревший файл lock.
3. Реализовать open/close с generation token и остановкой наблюдений; смена произвольных коллекций добавится позднее.

## Критерии готовности

- [ ] Второй процесс не открывает тот же контейнер на запись.
- [ ] Запоздавший результат закрытого контекста не меняет новое окно.

## Проверка

Два тестовых владельца, завершение процесса и повторное открытие; сверка manifest UUID с БД.
