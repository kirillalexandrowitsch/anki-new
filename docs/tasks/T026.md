# T026 · Добавить главные команды и keyboard routing

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** готово. **Этап:** M1. **Сложность:** M.

## Результат

Использовать одни действия из меню, кнопок и клавиш.

## Зависимости

[T002](T002.md) · [T019](T019.md) · [T025](T025.md)

## Область изменений

Предлагаемые файлы/модули: `App/Commands/; Features/Navigation/`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Завести command IDs, focused context и маршруты главных разделов.
2. Добавить стандартные create/edit/import/settings действия с disabled conditions.
3. Для Study маршрутизировать Space/1–4 по состоянию и не перехватывать ввод текста/модальный диалог.

## Критерии готовности

- [ ] Одна команда имеет одинаковый результат из разных точек входа.
- [ ] В активном поле Space и цифры вводятся, а не ставят оценку.

## Проверка

Клавиатурный проход Today → study → editor и проверка отключённых menu items.
