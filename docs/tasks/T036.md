## Результат

Добавить управляемое форматирование и медиа в EditorDraft.

## Зависимости

[T009](T009.md) · [T015](T015.md) · [T021](T021.md)

## Область изменений

Предлагаемые файлы/модули: `Features/Editor; DesignSystem/RichText`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Реализовать ограниченный rich text AST и toolbar bold/italic/underline.
2. Добавить выбор изображения/аудио, preview и подтверждение удаления attachment.
3. Разделить Apply в медиа-диалоге и Save Note; Cancel очищает временный staging без правки сохранённой Note.

## Критерии готовности

- [ ] Форматирование сохраняется в структурированном виде и восстанавливается.
- [ ] Удаление вложения не удаляет общий файл другой записи.

## Проверка

Открыть/применить/отменить вложение, invalid media и round trip formatting.
