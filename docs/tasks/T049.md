## Область изменений

Предлагаемые файлы/модули: `CardsDesignSystem; CardsFeatures/`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Пройти loading/empty/error/disabled/focus для каждого feature.
2. Добавить конкретные next actions вместо технических stack traces.
3. Убрать фиктивные проценты прогресса, проверить retry/cancel и повторный запуск операции.

## Критерии готовности

- [ ] Нет вечного spinner после ошибки.
- [ ] Цвет не единственный признак ошибки и недоступности.

## Проверка

Fault-injection walkthrough всех основных экранов; ручной keyboard focus audit.
