# T076 · Сделать типы записей и редактор полей

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M4. **Сложность:** L.

## Результат

Развить встроенные типы в управляемые схемы.

## Зависимости

[T014](T014.md) · [T037](T037.md) · [T068](T068.md)

## Область изменений

Предлагаемые файлы/модули: `Features/Types; Core/UseCases/NoteTypes`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Добавить список типов, duplicate и immutable stable IDs полей.
2. Редактировать required/optional, order и добавление field без потери старых values.
3. Отдельно анализировать удаление используемого поля и затронутые templates/Notes до Apply.

## Критерии готовности

- [ ] Переименование поля не меняет ключ сохранённых данных.
- [ ] Опасное изменение имеет preview и проверенную копию.

## Проверка

Тип с несколькими Notes, rename/reorder и отказ удаления обязательного используемого поля.
