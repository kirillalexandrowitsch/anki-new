## Область изменений

Предлагаемые файлы/модули: `docs/acceptance/core-ui; UITests/`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Пройти каждый panel ID по TRACEABILITY и сохранить результат/отличие.
2. Проверить main navigation, редактор, Study, settings и errors как связный сценарий.
3. Отметить APKG и hardening как следующий milestone, не оставлять доступных заглушек.

## Критерии готовности

- [ ] Все 96 основных панелей имеют реализованное состояние либо явный открытый дефект.
- [ ] Нет нарушения правил reveal/ratings, modal Cancel и autosave.

## Проверка

Ручная state matrix, targeted XCUITests и два theme/window variants.
