## Результат

Получать актуальные списки без загрузки всей коллекции.

## Зависимости

[T006](T006.md) · [T008](T008.md)

## Область изменений

Предлагаемые файлы/модули: `Core/Queries/; Infrastructure/Queries/`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Создать query DTO для колод, библиотеки, Today и счётчиков.
2. Поднять FTS5 front/back/examples, параметризованные запросы, pagination и стабильный tie-breaker.
3. Связать GRDB observation с async snapshots и отменой по lifecycle/generation.

## Критерии готовности

- [ ] Сохранение Note обновляет список и индекс.
- [ ] Закрытый экран не оставляет бесконечное наблюдение или N+1 query на строку.

## Проверка

Сверить результаты фильтра, пагинации и FTS после изменения; проверить отмену observation.
