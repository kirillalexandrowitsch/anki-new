# T058 · Реализовать APKG экспорт содержимого

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M3. **Сложность:** L.

## Результат

Создавать поддержанный Anki deck package без истории.

## Зависимости

[T027](T027.md) · [T037](T037.md) · [T055](T055.md) · [T056](T056.md)

## Область изменений

Предлагаемые файлы/модули: `Infrastructure/ImportExport/APKG/`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Преобразовать собственные поля/варианты в матрицу поддержанных Anki note types.
2. Экспортировать deck subtree, tags и media mapping с корректными внешними IDs.
3. Записывать временный архив, проверить чтение/целостность, затем replace destination.

## Критерии готовности

- [ ] Экспорт открывается в чистом профиле тестовой Anki.
- [ ] Несовместимый собственный шаблон имеет preview потерь или явный отказ.

## Проверка

Внешний Anki import для Basic/Reverse/Cloze/Typed и медиа; не только self-round-trip.
