## Область изменений

Предлагаемые файлы/модули: `Features/Onboarding; App/CollectionCoordinator`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Сделать пропускаемый короткий tour с устойчивыми anchors.
2. Дать выбор empty/demo/import, не повторяя onboarding после успешного завершения.
3. Показать migration progress и collection already open с переходом к владельцу/другому выбору без force overwrite.

## Критерии готовности

- [ ] Skip tour не теряет работу и не создаёт демонстрационные данные.
- [ ] Занятая коллекция никогда не предлагается к принудительной записи.

## Проверка

Миграционный fixture, занятый lock, повторный запуск и недоступная tour anchor.
