# T064 · Принять APKG совместимость на внешнем Anki

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

## Результат

Подтвердить заявленный объём совместимости независимо от собственного reader.

## Область изменений

Предлагаемые файлы/модули: `docs/APKG_COMPATIBILITY.md; Tests/Acceptance`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Пройти матрицу supported/rejected на конкретной тестовой версии Anki.
2. Сверить Note/Card counts, поля, медиа, tags, directions, scheduling и повторный импорт.
3. Опубликовать ограничения и воспроизводимые steps рядом с форматом; убрать неподтверждённые обещания UI.

## Критерии готовности

- [ ] Каждая supported строка имеет pass evidence.
- [ ] Rejected варианты распознаны до записи и дают полезное действие.

## Проверка

Двусторонний обмен в чистых профилях с сохранением fixture hashes.
