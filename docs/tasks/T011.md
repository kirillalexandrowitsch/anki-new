## Область изменений

Предлагаемые файлы/модули: `Infrastructure/Backup/`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Снять согласованный SQLite snapshot и список immutable media под operation lease.
2. Создать versioned manifest с hash и архив без WAL/locks/cache.
3. Проверять восстановление в staging, делать swap с внешним rollback journal и recovery при старте.

## Критерии готовности

- [ ] Точная копия восстанавливается в другой контейнер.
- [ ] Повреждённый архив не заменяет текущую коллекцию.

## Проверка

Round trip Notes/Cards/log/media и падение между двумя rename; сравнить содержимое после recovery.
