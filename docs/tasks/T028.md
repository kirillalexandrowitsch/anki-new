# T028 · Реализовать первичную статистику

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** готово. **Этап:** M1. **Сложность:** M.

## Результат

Показывать измерения из журнала оценок.

## Зависимости

[T010](T010.md) · [T020](T020.md) · [T022](T022.md)

## Область изменений

Предлагаемые файлы/модули: `Core/Queries/Stats; Features/Statistics/`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Создать StatsQueryService с effective events и едиными day keys.
2. Показать количества, grade breakdown, active duration и простую активность Swift Charts.
3. Нулевые данные отличать от 0%/100%; подписи объясняют оценки против уникальных Card.

## Критерии готовности

- [ ] Undo меняет все связанные метрики согласованно.
- [ ] Графики не используют числа из PNG вместо реальных запросов.

## Проверка

Сверка ручного fixture log со всеми показателями, пустой период и отменённая оценка.
