# T087 · Поддержать несколько окон и полноэкранное занятие

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M4. **Сложность:** L.

## Результат

Открывать редактор отдельно и адаптировать рабочее пространство.

## Зависимости

[T048](T048.md) · [T050](T050.md) · [T083](T083.md) · [T086](T086.md)

## Область изменений

Предлагаемые файлы/модули: `App/Windows; Features/Editor/Study`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Сделать отдельный Editor window с собственным draft/revision и общей коллекцией.
2. Определить поведение одновременных правок, одного активного Study и Close/Quit.
3. Проверить обычное/компактное/fullscreen, скрываемый inspector и системные Window commands.

## Критерии готовности

- [ ] Окна не теряют drafts и не перезаписывают изменения молча.
- [ ] Смена коллекции проходит unsaved flow для всех затронутых окон.

## Проверка

Два редактора одной Note, конфликт Save, fullscreen exit и collection switch.
