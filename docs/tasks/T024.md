# T024 · Реализовать первый запуск

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** готово. **Этап:** M1. **Сложность:** M.

## Результат

Провести пользователя к первой колоде без навязанного наполнения.

## Зависимости

[T013](T013.md) · [T014](T014.md) · [T015](T015.md) · [T023](T023.md)

## Область изменений

Предлагаемые файлы/модули: `Features/Onboarding/`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Добавить welcome, create/import выбор и короткий ввод названия.
2. Демо-три записи добавлять только по выбранному сценарию, записывать onboarding completion.
3. По успеху показать первую колоду и Start, по Cancel оставить пустое состояние; импортную ветку включить после готовности мастера T051.

## Критерии готовности

- [ ] Повторный запуск не размножает demo Notes.
- [ ] До T051 импортная ветка явно недоступна; после подключения открывает мастер и не создаёт скрытую пустую колоду.

## Проверка

Первый/повторный запуск, отмена и сбой создания между шагами.
