## Результат

Выбирать действительно доступные карточки без дублирования квот.

## Зависимости

[T005](T005.md) · [T010](T010.md) · [T014](T014.md) · [T017](T017.md)

## Область изменений

Предлагаемые файлы/модули: `Core/Study/QueueBuilder/`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Реализовать scope с потомками, learning/review/new priority и исключения suspend/bury/delete.
2. Добавить study day, уникальные new/review quota, session limit и sibling policy.
3. Возвращать ready, futureDue и empty причины отдельно; пересверять eligibility перед показом.

## Критерии готовности

- [ ] Parent scope не дублирует CardID из дочерних колод.
- [ ] Future learning не показывается раньше времени, пустота не маскирует ошибку.

## Проверка

Fixtures на DST/rollover, siblings, исчерпанный лимит, повторный Again и reset той же Card.
