## Результат

Управлять тегами и связями в масштабе коллекции.

## Зависимости

[T038](T038.md) · [T068](T068.md)

## Область изменений

Предлагаемые файлы/модули: `Features/Library/Tags; Core/UseCases/Tags`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Добавить searchable list, card/note counts, цвет и rename validation.
2. Объединять source→target с preview affected Notes и дедупликацией связей.
3. Удалять тег после подтверждения, сохраняя сами Notes/Cards; saved filters получают missing-condition state.

## Критерии готовности

- [ ] Rename сохраняет tagID и фильтры не ломаются по одному имени.
- [ ] Delete удаляет associations, а не учебный материал.

## Проверка

Merge одного и нескольких тегов, duplicate name и filter после удаления.
