## Результат

Сделать понятные диагностику и исправление коллекции.

## Зависимости

[T053](T053.md) · [T061](T061.md) · [T083](T083.md)

## Область изменений

Предлагаемые файлы/модули: `Features/Settings/Data/Maintenance`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Добавить summary integrity scan и отдельные missing/unused media lists.
2. Repair by locating file проверяет тип/hash и обновляет refs только после подтверждения.
3. Доработать disk-full/corrupt-copy paths и Retry/Choose another folder без ложного успеха.

## Критерии готовности

- [ ] Удаление unused не затрагивает другие коллекции или активный staging.
- [ ] Ошибка restore оставляет текущую коллекцию открываемой.

## Проверка

Подготовленный damaged fixture, недостаток места и восстановление после прерванного repair.
