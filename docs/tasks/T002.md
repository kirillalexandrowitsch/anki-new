## Область изменений

Предлагаемые файлы/модули: `App/ и Packages/CardsKit/`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Создать App target, CardsCore/Infrastructure/DesignSystem/Features и тестовые targets.
2. Подключить локальный пакет, shared schemes, ресурсы локализации и composition root без singleton базы. Задать app.project/app.scheme/packagePaths в .github/automation.json для обязательной сборки и тестов CI.
3. Добавить пять разделов, Settings scene, базовый App Sandbox и начальные file-selection capabilities; настроить Git локально и исключения build/cache/личных коллекций.

## Критерии готовности

- [ ] Приложение запускается на arm64; циклов зависимостей нет.
- [ ] Core компилируется без SwiftUI/GRDB; дизайн-PNG не копируются в bundle.
- [ ] CI знает shared scheme приложения и все локальные Swift packages; xcodebuild test выполняется на macOS runner.

## Проверка

Clean build приложения и swift test каркаса; проверить build settings в shared scheme.
