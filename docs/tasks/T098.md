## Результат

Дать понятные инструкции установки, работы и восстановления.

## Зависимости

[T069](T069.md) · [T090](T090.md) · [T095](T095.md) · [T097](T097.md)

## Область изменений

Предлагаемые файлы/модули: `Features/Help; docs/user-guide/`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Описать Card/Note, reveal/ratings, CSV/APKG limits, backup и switch collections.
2. Сделать явный redacted diagnostic export без текстов/аудио и приватных путей.
3. Добавить local Help shortcuts и troubleshooting permissions/disk-full/corrupt backup.

## Критерии готовности

- [ ] Инструкция соответствует работающим функциям и текущей compatibility matrix.
- [ ] Diagnostic export создаётся только по команде и показывает состав.

## Проверка

Новый тестовый пользователь проходит первый study и восстановление по инструкции.
