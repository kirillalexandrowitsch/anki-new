# T015 · Сделать базовый редактор карточки

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** готово. **Этап:** M1. **Сложность:** M.

## Результат

Создавать и изменять содержимое через явный редактор.

## Зависимости

[T004](T004.md) · [T010](T010.md) · [T014](T014.md)

## Область изменений

Предлагаемые файлы/модули: `Features/Editor/`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Добавить EditorDraft, выбор колоды, front/back/example/pronunciation и preview.
2. Разделить empty/valid/invalid/saving/conflict states; Save вызывает один use case.
3. Показывать unsaved warning при уходе и не перехватывать текстовые клавиши навигацией.

## Критерии готовности

- [ ] Невалидный front/back не сохраняется.
- [ ] Save/Discard/Cancel при закрытии имеют разные проверяемые результаты.

## Проверка

UI-сценарий создания и изменения; конфликт двух drafts и ошибка диска.
