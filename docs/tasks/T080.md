# T080 · Создавать карточки из вставленного текста

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M4. **Сложность:** M.

## Результат

Превращать выделенные слова в вручную заполненные записи.

## Зависимости

[T015](T015.md) · [T038](T038.md) · [T074](T074.md) · [T079](T079.md)

## Область изменений

Предлагаемые файлы/модули: `Features/Library/TextToCards/`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Создать локальный text workspace и выделение слов с Create Card.
2. Подставлять исходное предложение как example, перевод оставлять ручным полем.
3. Массовый список валидировать до Add и применять через общий import/save plan.

## Критерии готовности

- [ ] Нет скрытого API перевода и сетевой отправки текста.
- [ ] Missing translation видна до commit, нельзя молча добавить пустые обязательные поля.

## Проверка

Unicode selection, одинаковые слова, несколько терминов и Cancel batch draft.
