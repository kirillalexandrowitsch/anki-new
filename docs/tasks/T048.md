# T048 · Унифицировать несохранённость и модальные возвраты

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

## Результат

Предотвращать потерю editor draft при навигации.

## Зависимости

[T015](T015.md) · [T025](T025.md) · [T036](T036.md) · [T040](T040.md) · [T046](T046.md) · [T047](T047.md)

## Область изменений

Предлагаемые файлы/модули: `Features/Common/Dialogs; App/Navigation`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Ввести общий unsaved decision flow для закрытия окна, смены раздела и коллекции.
2. Проверить различие editor Save, settings autosave и modal Apply.
3. Восстанавливать исходный фокус, не применять draft по Escape и не запускать destructive default Return.

## Критерии готовности

- [ ] Save/Discard/Cancel имеют одинаковую семантику во всех входах.
- [ ] Ошибка Save оставляет editor draft открытым.

## Проверка

Матрица закрытия кнопкой окна, Escape, menu Quit и route change.
