# T032 · Сделать меню, свойства и настройку занятия

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M2. **Сложность:** M.

## Результат

Связать действия колоды с понятным запуском занятия.

## Зависимости

[T018](T018.md) · [T023](T023.md) · [T031](T031.md)

## Область изменений

Предлагаемые файлы/модули: `Features/Decks/Inspectors; Features/Study/Setup`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Добавить overflow menu с доступностью команд по контексту.
2. Сделать inspector свойств и настройку new/review/session limits без изменения постоянного preset.
3. Начинать сессию из validated scope; показать точные значения и причину недоступности Start.

## Критерии готовности

- [ ] Меню не предлагает активных пустых заглушек.
- [ ] Настройка сессии влияет на выбранное занятие, не скрыто меняет лимиты навсегда.

## Проверка

Все menu routes, пустая колода, child scope и сохранение постоянных настроек после Cancel.
