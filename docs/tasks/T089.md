# T089 · Добавить расширенные разрезы аналитики

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M4. **Сложность:** L.

## Результат

Показать интервалы, сложность, время и историю сессий.

## Зависимости

[T043](T043.md) · [T066](T066.md) · [T071](T071.md) · [T072](T072.md)

## Область изменений

Предлагаемые файлы/модули: `Core/Queries/Stats; Features/Statistics/Advanced`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Гистограмма интервалов и difficulty distribution используют определённые единицы/параметры.
2. Heatmap времени считает реальные active intervals, session list раскрывает breakdown.
3. Drill-down hard cards открывает Library filter; preview sessions отделяются от scheduling statistics.

## Критерии готовности

- [ ] Новый график не вводит неопределённое значение «сложность».
- [ ] Каждый график имеет текстовые данные и корректное no-data состояние.

## Проверка

Reference fixture с разными эпохами, режимами сессии, Undo и timezone.
