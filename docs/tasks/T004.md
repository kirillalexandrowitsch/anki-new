## Результат

Перевести визуальные правила в переиспользуемые нативные компоненты.

## Зависимости

[T002](T002.md)

## Область изменений

Предлагаемые файлы/модули: `CardsDesignSystem/`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Создать semantic colors, type scale, spacing и radii из DESIGN.md со светлой/тёмной темой.
2. Добавить primary/secondary/destructive buttons, labelled field, panel, banner, empty/loading и focus states.
3. Создать preview gallery для normal/hover/pressed/disabled/error; применить системные SF Symbols и размер текста.

## Критерии готовности

- [ ] Компоненты не знают о моделях коллекции.
- [ ] Ошибка, disabled и focus различимы без одного только цвета.

## Проверка

Визуально проверить previews в двух темах и с крупным текстом; выборочные snapshots только стабильных элементов.
