# T046 · Сделать UI копий и восстановления

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M2. **Сложность:** M.

## Результат

Дать пользователю контроль резервных копий.

## Зависимости

[T011](T011.md) · [T025](T025.md) · [T035](T035.md)

## Область изменений

Предлагаемые файлы/модули: `Features/Settings/Data/`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Показать список, дату, размер, состояние проверки и создание копии с прогрессом.
2. Восстановление подтверждает замену и вызывает staging/swap service.
3. Удаление копии отдельно подтверждается, default retention не удаляет pinned backups.

## Критерии готовности

- [ ] Ошибка создания не показывает success и не удаляет предыдущую копию.
- [ ] Cancel восстановления сохраняет текущую коллекцию.

## Проверка

Создание/удаление/восстановление, corrupt backup и отказ доступа папке.
