# T014 · Сохранять словарные записи и Basic Card

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** готово. **Этап:** M1. **Сложность:** M.

## Результат

Связать содержимое записи с независимой учебной карточкой.

## Зависимости

[T005](T005.md) · [T008](T008.md) · [T013](T013.md)

## Область изменений

Предлагаемые файлы/модули: `Core/UseCases/Notes; Infrastructure/Repositories/`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Создать встроенный Basic NoteType со стабильными field/template IDs.
2. Реализовать SaveNote: поля, теги/медиа refs и генерация basic.forward в одной транзакции.
3. При повторном Save сохранять CardID/schedule, учитывать suppressed variant.

## Критерии готовности

- [ ] Одна Note создаёт одну Basic Card с новым расписанием.
- [ ] Редактирование перевода не сбрасывает прогресс и не создаёт дубликат.

## Проверка

Create/edit/reopen и повторный Save после suppression; проверить ID и schedule revision.
