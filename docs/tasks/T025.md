# T025 · Сделать четыре вкладки настроек и autosave

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** готово. **Этап:** M1. **Сложность:** M.

## Результат

Разделить app preferences, collection settings и модальные drafts.

## Зависимости

[T004](T004.md) · [T008](T008.md) · [T023](T023.md)

## Область изменений

Предлагаемые файлы/модули: `Features/Settings; Infrastructure/Preferences/`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Создать Основные/Повторение/Карточки/Данные, без пятой вкладки hotkeys.
2. Добавить тему/язык и начальные учебные параметры с валидируемым autosave.
3. Хранить внешний вид в UserDefaults, учебные настройки в SQLite; на ошибке показывать сохранённое значение.

## Критерии готовности

- [ ] Настройки переживают перезапуск и не смешиваются с editor drafts.
- [ ] Невалидное промежуточное число не фиксируется.

## Проверка

Изменение темы/лимита, недопустимый ввод и эмуляция ошибки сохранения.
