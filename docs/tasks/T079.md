# T079 · Расширить редактор примерами, drag-and-drop и добавлением

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M4. **Сложность:** M.

## Результат

Ускорить наполнение без нарушения explicit save.

## Зависимости

[T036](T036.md) · [T037](T037.md) · [T048](T048.md) · [T078](T078.md)

## Область изменений

Предлагаемые файлы/модули: `Features/Editor/`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Добавить несколько example pairs с порядком и удалением.
2. Создавать stable cloze из выделения, принимать локальный drag-and-drop через MediaStore.
3. Save and add another сохраняет одну Note, удерживает deck/type и очищает новые поля после commit; duplicate warning не блокирует разные смыслы молча.

## Критерии готовности

- [ ] Ошибка Save сохраняет весь текущий draft.
- [ ] Новая пустая форма появляется только после успешной записи предыдущей.

## Проверка

Drag corrupt file, reorder примеров, overlapping cloze selection и повторный клик Save.
