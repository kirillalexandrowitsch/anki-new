# T084 · Переименовывать и удалять коллекции

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M4. **Сложность:** M.

## Результат

Чётко разделить удаление из списка и уничтожение данных.

## Зависимости

[T065](T065.md) · [T083](T083.md)

## Область изменений

Предлагаемые файлы/модули: `Features/Collections/Management; Infrastructure/Collections`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Rename обновляет registry/manifest/meta без изменения UUID.
2. Remove from list — default безопасная команда, папка остаётся.
3. Delete local data — отдельное подтверждение с точным именем, backup option и проверкой активного lock/окон.

## Критерии готовности

- [ ] Удаление записи registry не удаляет файлы.
- [ ] Активный контейнер не уничтожается мимо lifecycle/recovery flow.

## Проверка

Rename, remove/reopen same folder, Cancel delete и занятая коллекция.
