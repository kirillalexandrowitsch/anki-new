# T072 · Доработать действия внутри занятия

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M4. **Сложность:** M.

## Результат

Дать Undo, bury, flag и помощь при частых ошибках.

## Зависимости

[T020](T020.md) · [T041](T041.md) · [T068](T068.md)

## Область изменений

Предлагаемые файлы/модули: `Features/Study/Actions; Core/UseCases`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Подключить готовый Undo к toolbar и доступным shortcuts.
2. Bury до следующего StudyDay и flag сохранять отдельными командами без раскрытия ответа.
3. Определить leech threshold как настройку, показать Edit/Suspend/Continue без оценочных заявлений о пользователе.

## Критерии готовности

- [ ] После bury следующая Card скрыта, изменение можно отменить при допустимой revision.
- [ ] Флажок не ставит оценку и не раскрывает скрытый текст.

## Проверка

Hidden/revealed контексты, midnight bury и конфликт Undo после новой команды.
