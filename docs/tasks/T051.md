## Результат

Импортировать содержимое через preview и явные решения.

## Зависимости

[T027](T027.md) · [T038](T038.md) · [T039](T039.md) · [T048](T048.md)

## Область изменений

Предлагаемые файлы/модули: `Features/Import; Infrastructure/ImportExport`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Сделать шаги file/mapping/preview/staging/apply/result с back/cancel.
2. Определять duplicate candidates, сохранять выбранное решение и обязательные поля.
3. Считать Notes/Cards отдельно; invalid rows показывать до применения, финальный commit атомарный.

## Критерии готовности

- [ ] Отмена до commit не оставляет часть колоды.
- [ ] Повторный импорт по внешнему источнику управляем, одно слово с другим значением не теряется молча.

## Проверка

Quoted CSV, duplicate policies, invalid mapping и crash before/after final commit.
