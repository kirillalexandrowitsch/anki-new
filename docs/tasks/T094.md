# T094 · Проверить приложение на ноутбуке владельца

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M5. **Сложность:** L.

## Результат

Подтвердить работу на конкретном MacBook и установленной macOS.

## Зависимости

[T067](T067.md) · [T086](T086.md) · [T087](T087.md) · [T092](T092.md)

## Область изменений

Предлагаемые файлы/модули: `docs/acceptance/local-platform`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Зафиксировать модель, arm64, установленную macOS, Xcode/SDK и версии зависимостей.
2. Пройти светлую/тёмную тему, разные размеры окна, keyboard/VoiceOver, файлы и аудио на этом Mac.
3. Проверку других macOS и Mac сделать необязательным расширением; не заявлять проверенную совместимость вне выполненных проверок.

## Критерии готовности

- [ ] Основной и расширенный сценарии проходят на ноутбуке владельца.
- [ ] Ограничения текущей системы документированы; дополнительные устройства/VM не блокируют личную готовность.

## Проверка

Локальная Release-сборка, отдельная тестовая коллекция и сохранённый протокол.
