## Результат

Применять команды к явному набору выбранных карточек.

## Зависимости

[T031](T031.md) · [T038](T038.md) · [T039](T039.md)

## Область изменений

Предлагаемые файлы/модули: `Features/Library/Bulk; Core/UseCases`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Добавить selection toolbar и контекстное меню одинаковых действий.
2. Реализовать MoveCards с preview количества, destination validation и revision проверки.
3. Определить Select all: текущая страница либо все результаты отдельным подтверждённым query snapshot.

## Критерии готовности

- [ ] Выбор не расширяется незаметно при смене фильтра.
- [ ] При конфликте показана причина, не получается половина незаявленного переноса.

## Проверка

Перенос нескольких вариантов общей Note, смена фильтра и конфликт revision.
