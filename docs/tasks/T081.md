# T081 · Добавить карточку на слух и скорость воспроизведения

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M4. **Сложность:** M.

## Результат

Поддержать аудиовопрос и управление локальным звуком.

## Зависимости

[T021](T021.md) · [T037](T037.md) · [T078](T078.md)

## Область изменений

Предлагаемые файлы/модули: `Core/Rendering; Features/Study/Audio`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Добавить audio variant с hidden word и Show answer.
2. Для файлов сделать seek/rate 0.75×/1×/1.25×; для TTS указать поддерживаемую семантику rate без ложного seek.
3. Сохранять настройку скорости отдельно от оценки и обрабатывать interruption.

## Критерии готовности

- [ ] Hidden word не раскрывается через подписи/VoiceOver раньше действия.
- [ ] Playback control не ставит оценку и не смешивает разные audio sources.

## Проверка

Audio-only Card, missing attachment, смена скорости, pause/replay и Reveal.
