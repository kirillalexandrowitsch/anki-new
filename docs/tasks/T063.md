## Область изменений

Предлагаемые файлы/модули: `Tests/Performance; Infrastructure/ImportExport`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Измерить parsing/apply/peak memory на предельном synthetic наборе.
2. Проверить ZIP entry/size limits, decode bounds, cancellation и краткость writer barrier.
3. Оптимизировать запросы/индексы или документировать shadow-database activation, сохранив атомарность.

## Критерии готовности

- [ ] Данные выше лимита получают контролируемый отказ.
- [ ] Во время разрешённого импорта UI отвечает, частичный результат не публикуется.

## Проверка

Большая легальная коллекция, zip bomb fixture малого размера и отмена анализа.
