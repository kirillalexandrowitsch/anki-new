# T045 · Настроить системные напоминания и разрешения

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M2. **Сложность:** M.

## Результат

Планировать локальные reminders по выбору пользователя.

## Зависимости

[T025](T025.md) · [T035](T035.md) · [T044](T044.md)

## Область изменений

Предлагаемые файлы/модули: `Infrastructure/Platform/Notifications; Features/Settings`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Запрашивать notification authorization при включении, не при первом запуске приложения.
2. Хранить время/дни, обновлять и отменять системные requests без дублей.
3. Показывать denied/restricted состояние, сохранять выбранное время и открывать системные настройки.

## Критерии готовности

- [ ] Выключение удаляет соответствующие pending requests.
- [ ] Отказ не блокирует настройки и не выдаётся за разрешение.

## Проверка

Allowed/denied, смена времени, timezone и запуск без ожидаемого системного баннера.
