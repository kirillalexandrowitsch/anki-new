## Область изменений

## Как выполнить

1. Для каждого base/panel ID записать реализацию, evidence и намеренное отклонение.
2. Все agreed changes обновить в PRODUCT/FLOWS/задачах; не считать визуальный вариант отдельной работающей функцией автоматически.
3. Незакрытые блокеры вернуть в конкретную task card с зависимостями.

## Критерии готовности

- [ ] Нет состояния без владельца и результата проверки.
- [ ] Предложенные расширения реализованы к полному milestone либо их изменение явно согласовано.
