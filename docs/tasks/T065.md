# T065 · Защитить полный сброс учебных данных

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M3. **Сложность:** L.

## Результат

Отделить полный сброс от удаления карточек и reset настроек.

## Зависимости

[T011](T011.md) · [T048](T048.md) · [T061](T061.md) · [T062](T062.md)

## Область изменений

Предлагаемые файлы/модули: `Features/Settings/Data; Core/UseCases/ResetCollection`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Показать имя коллекции, состав потери данных и предложение backup.
2. Требовать точное имя в пустом confirmation field; destructive button до совпадения disabled.
3. Применять через safe container replacement с recovery, пересоздать контекст без старых callbacks.

## Критерии готовности

- [ ] Cancel и пустой/неверный текст ничего не удаляют.
- [ ] После подтверждения не остаётся старой истории в активной коллекции.

## Проверка

Неверное/точное имя, backup failure, crash swap и stale window callback.
