# T073 · Сделать условия поиска и сохранённые фильтры

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M4. **Сложность:** L.

## Результат

Составлять сложные запросы без ввода SQL.

## Зависимости

[T039](T039.md) · [T068](T068.md)

## Область изменений

Предлагаемые файлы/модули: `Core/Queries/SearchAST; Features/Library/Search`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Добавить AST deck/status/tag/word с AND/OR и whitelist операторов.
2. Отображать query builder и cancellable preview с debounce.
3. Сохранять именованный versioned filter; удалённые deck/tag references показывать как invalid condition.

## Критерии готовности

- [ ] Saved filter восстанавливает ту же семантику после перезапуска.
- [ ] Пользовательский текст не превращается в SQL/FTS control syntax.

## Проверка

Вложенные условия, специальные символы, missing tag и schema migration saved query.
