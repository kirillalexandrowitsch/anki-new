## Результат

Находить повреждения и предлагать безопасное исправление.

## Зависимости

[T009](T009.md) · [T046](T046.md) · [T053](T053.md) · [T054](T054.md)

## Область изменений

Предлагаемые файлы/модули: `Infrastructure/Maintenance; Features/Settings/Data`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Добавить integrity/foreign keys/domain checks и разделённый media scan.
2. Missing media исправлять выбором файла, unused media удалять после preview с учётом pending operations.
3. Недостаток места и corrupt backup показывать без замены текущей коллекции.

## Критерии готовности

- [ ] Scan не удаляет найденное автоматически.
- [ ] Проверка и исправление различаются командами и подтверждением.

## Проверка

Missing/hash-mismatch/unreferenced assets, disk-full и неверная backup schema.
