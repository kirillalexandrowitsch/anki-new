# T071 · Сделать свободное повторение и временные колоды

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M4. **Сложность:** L.

## Результат

Проводить занятия по ошибкам, тегам и фильтрам без перемещения оригиналов.

## Зависимости

[T018](T018.md) · [T032](T032.md) · [T038](T038.md) · [T068](T068.md)

## Область изменений

Предлагаемые файлы/модули: `Core/Study/CustomSession; Features/Study/Setup`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Ввести versioned SessionMode: scheduled/custom-reschedule/preview-no-reschedule.
2. Сделать include/exclude tags, count preview и temporary deck как query definition.
3. Добавить day-limit override и явный выбор Finish/Increase; пояснять влияет ли занятие на расписание.

## Критерии готовности

- [ ] Временная колода сохраняет original deckID всех Card.
- [ ] Preview mode не создаёт обычные scheduling reviews и не искажает квоты.

## Проверка

Rebuild временной выборки, пустые теги, quota override и одинаковая Card в двух scopes.
