# T034 · Сделать глобальный поиск и слово дня

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M2. **Сложность:** M.

## Результат

Находить карточки/колоды и показывать локальное слово дня.

## Зависимости

[T010](T010.md) · [T016](T016.md) · [T021](T021.md) · [T023](T023.md)

## Область изменений

Предлагаемые файлы/модули: `Features/Today/Search; Core/Queries`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Добавить toolbar search popover с группами Card/Deck, keyboard selection и empty action.
2. Выбор результата открывает существующий route, не создаёт копию Note.
3. Выбирать слово дня из локальной коллекции детерминированно по дню; Другое слово исключает текущее, озвучивание общее.

## Критерии готовности

- [ ] Поиск по panel-like special symbols безопасен и не блокирует UI.
- [ ] Без подходящих локальных слов показывается пустое состояние без внешнего запроса.

## Проверка

Keyboard поиск/переход, zero results, коллекция из одной записи и смена дня.
