# T083 · Сделать выбор и смену коллекций

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M4. **Сложность:** L.

## Результат

Открывать разные локальные коллекции без смешивания контекстов.

## Зависимости

[T007](T007.md) · [T048](T048.md) · [T054](T054.md) · [T068](T068.md)

## Область изменений

Предлагаемые файлы/модули: `Features/Collections; App/CollectionCoordinator`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Добавить registry chooser, create empty/import и last-opened metadata.
2. Перед switch решить unsaved editor, закрыть session/audio/observers и получить новый lock.
3. Внешние папки открывать через bookmark; generation invalidates старые callbacks.

## Критерии готовности

- [ ] В каждый момент одна активная коллекция на app context.
- [ ] Отмена switch сохраняет старую коллекцию и draft.

## Проверка

Две коллекции с одинаковыми NoteIDs в fixtures, blocked lock, stale bookmark и slow callback.
