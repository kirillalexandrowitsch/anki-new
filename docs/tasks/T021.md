# T021 · Добавить воспроизведение и системное произношение

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M1. **Сложность:** M.

## Результат

Слушать локальное аудио и доступный голос без блокирования занятия.

## Зависимости

[T009](T009.md) · [T019](T019.md)

## Область изменений

Предлагаемые файлы/модули: `Infrastructure/Media; Features/Study/Editor`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Создать playback coordinator для attached audio и доступных en-GB/en-US voices.
2. Добавить stop/replay и прекращение старого звука при смене карточки/коллекции.
3. Показать missing file/voice/error и уважать настройку автоматического воспроизведения.

## Критерии готовности

- [ ] Один источник звучит в каждый момент; ошибка не блокирует reveal/rating.
- [ ] Отсутствующий голос не выдаётся за успешно воспроизведённый.

## Проверка

Файлы good/missing/corrupt, смена Card во время playback и offline с установленным голосом.
