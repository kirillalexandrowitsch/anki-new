## Результат

Давать предпросмотр массовых изменений и объединений.

## Зависимости

[T040](T040.md) · [T048](T048.md) · [T051](T051.md) · [T073](T073.md)

## Область изменений

Предлагаемые файлы/модули: `Features/Library/BulkEdit; Core/UseCases/Merge`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Построить before/after plan по стабильному набору Notes с revision.
2. Сравнивать duplicate candidates по front и содержимому, не удалять автоматически.
3. Merge описывает судьбу вариантов, tags, media и отдельных schedules; несовместимое объединение требует выбора, точной истории не выдумывать.

## Критерии готовности

- [ ] Apply меняет ровно согласованный snapshot.
- [ ] Cancel и конфликт revision оставляют исходные записи целыми.

## Проверка

Shared Note selection, неоднозначные значения слова, schedule conflict и rollback.
