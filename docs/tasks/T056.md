## Область изменений

Предлагаемые файлы/модули: `Infrastructure/ImportExport/APKG/`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Распознавать вариант до распаковки и применять resource/path limits.
2. Читать external Notes/Cards/types/decks и создавать стабильное ID mapping.
3. Конвертировать безопасную разметку, отмечать неподдержанные шаблоны/поля в diagnostics.

## Критерии готовности

- [ ] Неподдержанный формат отклоняется до записи с инструкцией.
- [ ] Preview не исполняет JavaScript и не загружает remote media.

## Проверка

Reader fixtures всех supported/rejected rows матрицы, path traversal и corrupt DB.
