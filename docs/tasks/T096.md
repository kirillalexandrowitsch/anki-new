## Результат

Получить воспроизводимую Release .app для личного использования.

## Зависимости

[T068](T068.md) · [T092](T092.md) · [T094](T094.md) · [T095](T095.md)

## Область изменений

Предлагаемые файлы/модули: `scripts/local-build; docs/LOCAL_BUILD.md`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Создать команду сборки arm64 .app с постоянным bundle ID, version/build и выбранным Xcode.
2. Проверить локальную/ad-hoc подпись и нужные entitlements; Developer ID, notarization и DMG не требовать для этой личной поставки.
3. Добавить установку в выбранную папку приложений и запуск; пользовательская коллекция лежит отдельно и не входит в bundle.

## Критерии готовности

- [ ] .app собирается по инструкции и запускается на ноутбуке владельца.
- [ ] Сборка и установка не требуют платной программы разработчика и не удаляют существующую коллекцию.

## Проверка

Локальный build/install/launch, перезапуск, import/export, microphone/bookmark smoke с фактическими разрешениями.

## Дизайн-референсы

Инфраструктурная задача без отдельного растрового экрана. Контракт задают [ARCHITECTURE.md](../ARCHITECTURE.md) и [DATA_MODEL.md](../DATA_MODEL.md).

Выполнять только описанную область. Общие правила сохранения, reveal/ratings и отмены — в [PRODUCT.md](../PRODUCT.md) и [REVIEW_ENGINE.md](../REVIEW_ENGINE.md); файловые операции — в [INTEGRATIONS.md](../INTEGRATIONS.md).
