# T038 · Добавить теги и массовое назначение

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M2. **Сложность:** M.

## Результат

Организовать Note через единые теги.

## Зависимости

[T008](T008.md) · [T015](T015.md) · [T016](T016.md)

## Область изменений

Предлагаемые файлы/модули: `Core/UseCases/Tags; Features/Library/Editor`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Сделать picker существующих тегов, create с цветом и duplicate validation.
2. В editor хранить выбор в draft, в bulk dialog явно разделить add/remove sets.
3. Дедуплицировать выбранные NoteID, если отмечены несколько Cards одной записи.

## Критерии готовности

- [ ] Теги одинаковы у связанных вариантов Note.
- [ ] Массовое действие показывает число Card и уникальных Notes, без двойных изменений.

## Проверка

Duplicate tag, mixed selection и Cancel массового диалога.
