# T016 · Сделать базовую библиотеку

**Статус:** готово. **Этап:** M1. **Сложность:** M.

## Результат

Показывать реальные карточки коллекции и открывать редактор.

## Зависимости

[T004](T004.md) · [T010](T010.md) · [T015](T015.md)

## Область изменений

Предлагаемые файлы/модули: `Features/Library/`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Построить table/list по query snapshots со стабильной selection.
2. Добавить поиск, базовый empty state, Add/Edit и инспектор содержимого.
3. Различать Card count и Note count; показывать направление варианта.

## Критерии готовности

- [ ] Новые и изменённые записи появляются без ручной перезагрузки.
- [ ] Пустая библиотека предлагает создание или импорт.

## Проверка

Создать запись из пустого состояния, выбрать строку и изменить её; проверить reopen.
