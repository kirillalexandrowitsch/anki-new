# T086 · Добавить расширенные настройки доступности

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M4. **Сложность:** M.

## Результат

Системно поддержать большой текст, контраст и Reduce Motion.

## Зависимости

[T004](T004.md) · [T044](T044.md) · [T067](T067.md) · [T068](T068.md)

## Область изменений

Предлагаемые файлы/модули: `Features/Settings/Accessibility; DesignSystem`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Проверить/добавить app overrides только там, где они не дублируют недоступно системные настройки.
2. Адаптировать row heights, borders и labels, не прятать обязательные действия.
3. Определить focus order всех новых managers и announce errors без перехвата фокуса.

## Критерии готовности

- [ ] Настройки действуют последовательно на Library/Editor/Study.
- [ ] Нет обрезания переводов и focus trap.

## Проверка

Ручной VoiceOver и keyboard audit расширений с максимальным поддержанным text size.
