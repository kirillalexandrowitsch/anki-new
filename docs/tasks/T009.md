# T009 · Создать хранилище медиа со staging

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M0. **Сложность:** L.

## Результат

Хранить вложения без сломанных ссылок после сбоя.

## Зависимости

[T007](T007.md) · [T008](T008.md)

## Область изменений

Предлагаемые файлы/модули: `Infrastructure/Media/`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Добавить проверку UTI/размера, hash naming и immutable Media files.
2. Реализовать journal стадий prepare/publish/commit/cleanup с восстановлением при запуске.
3. Создавать thumbnails ImageIO вне main thread; не удалять orphan files до проверки активных операций.

## Критерии готовности

- [ ] В БД не появляется ссылка на ещё не опубликованный файл.
- [ ] Один и тот же файл дедуплицируется по SHA-256.

## Проверка

Fault injection между publish и commit, повреждённое изображение и повторное добавление.
