# T019 · Сделать экран занятия и автомат состояний

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M1. **Сложность:** L.

## Результат

Показать скрытый вопрос и корректно раскрывать ответ.

## Зависимости

[T004](T004.md) · [T018](T018.md)

## Область изменений

Предлагаемые файлы/модули: `Features/Study/`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Реализовать loading/question/answer/committing/paused/completed с явными допустимыми событиями.
2. В question оставить Показать ответ, пропуск и звук; после reveal показать ровно четыре оценки.
3. Настроить keyboard routing Space/1–4 вне текстовых полей, pause и exit confirmation.

## Критерии готовности

- [ ] Оценка недоступна до reveal и повторно во время committing.
- [ ] Следующий вопрос скрыт; Escape отменяет подтверждение выхода.

## Проверка

UI-тест скрытых/раскрытых контролов, клавиш и возврата из pause.
