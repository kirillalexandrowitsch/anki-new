# T088 · Реализовать переходы из раскадровки

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M4. **Сложность:** M.

## Результат

Добавить короткую обратную связь без изменения логики.

## Зависимости

[T019](T019.md) · [T049](T049.md) · [T086](T086.md) · [T087](T087.md)

## Область изменений

Предлагаемые файлы/модули: `DesignSystem/Motion; Features/Common`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Ввести motion tokens для reveal/next/modal/toast по предложенным временам.
2. Связать смену UI с commit, не скрывать ошибку завершённой анимацией.
3. Reduce Motion использует мгновенную смену/спокойный fade, focus сохраняется.

## Критерии готовности

- [ ] Во время перехода нельзя оценить скрытую или уже обработанную Card.
- [ ] Скорость анимации не меняет расписание и длительность хранения данных.

## Проверка

Быстрые клики, Reduce Motion, UI interruption и ошибка commit во время visual transition.
