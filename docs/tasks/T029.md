# T029 · Сделать удаление карточки с отменой 5 секунд

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** готово. **Этап:** M1. **Сложность:** M.

## Результат

Удалять выбранную Card без мгновенной потери содержимого.

## Зависимости

[T008](T008.md) · [T014](T014.md) · [T016](T016.md) · [T020](T020.md)

## Область изменений

Предлагаемые файлы/модули: `Core/UseCases/Delete; Features/Library/`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Показать подтверждение с областью удаления и связанной Note.
2. Записать tombstone/suppression/deletion batch, исключить из queue/list.
3. Показать Undo на 5 секунд; delayed purge не удаляет media активного undo.

## Критерии готовности

- [ ] Cancel не меняет данные; Undo возвращает Card и её прогресс.
- [ ] Поздний Save Note не создаёт удалённый вариант снова.

## Проверка

Cancel/delete/undo/timeout и restart во время окна отмены; fake monotonic clock.
