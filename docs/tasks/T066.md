Предлагаемые файлы/модули: `Tests/Integration/Statistics`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Составить reference log с Undo/reset/move/delete/import/progress events.
2. Сверить Today, session summary и Statistics по единым определениям.
3. Проверить исторические deck snapshots, timezone, zero denominators и rebuild кэша.

## Критерии готовности

- [ ] Итоги соответствуют эффективным log events, не текущему числу строк Cards.
- [ ] Кэш пересоздаётся без потери источника данных.

## Проверка
