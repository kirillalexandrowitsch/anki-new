# T033 · Удалять колоды с явной областью последствий

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M2. **Сложность:** M.

## Результат

Безопасно удалить колоду, её потомков и входящие Card.

## Зависимости

[T029](T029.md) · [T031](T031.md)

## Область изменений

Предлагаемые файлы/модули: `Core/UseCases/Decks/Delete; Features/Decks`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Собрать affected IDs, количество Card/Notes и вложенных колод до подтверждения.
2. Применить tombstones одной командой, общие Notes не удалять при живых вариантах в других колодах.
3. Перевести открытые экраны и очередь в корректное состояние после commit.

## Критерии готовности

- [ ] Подтверждение называет колоду и объём удаления.
- [ ] Связанные варианты за пределами выбранного поддерева остаются доступны.

## Проверка

Cancel, вложенное удаление, общая Note в двух колодах и сбой транзакции.
