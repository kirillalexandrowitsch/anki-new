# T022 · Сохранять паузу, прогресс сессии и итоги

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M1. **Сложность:** M.

## Результат

Продолжать занятие после паузы и перезапуска без повторных оценок.

## Зависимости

[T019](T019.md) · [T020](T020.md)

## Область изменений

Предлагаемые файлы/модули: `Core/Study/SessionService; Features/Study/`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Сохранять checkpoint после действий и состояние prior-to-pause.
2. Реализовать Skip без ReviewLog, early finish confirmation и completed summary.
3. Считать active duration без pause/sleep/idle; восстановление открывает неоценённый вопрос скрытым.

## Критерии готовности

- [ ] Пауза возвращает тот же текущий вопрос/ответ до перезапуска.
- [ ] Перезапуск не создаёт повторных log и не теряет подтверждённые оценки.

## Проверка

Пауза, сон, force quit после оценки, Skip всех доступных Card и досрочный выход.
