# T062 · Проверить Sandbox и долговременный файловый доступ

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M3. **Сложность:** M.

## Результат

Обеспечить работу файловых сценариев в реальной sandboxed сборке.

## Зависимости

[T027](T027.md) · [T045](T045.md) · [T050](T050.md) · [T060](T060.md) · [T061](T061.md)

## Область изменений

Предлагаемые файлы/модули: `App/Entitlements; Infrastructure/Platform`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Добавить минимальные user-selected read/write и bookmark capabilities.
2. Проверять stale bookmarks, доступ после перезапуска и корректный stopAccessing scope.
3. Запретить рабочую БД в сетевой/синхронизируемой папке; предложить локальное хранилище и экспорт.

## Критерии готовности

- [ ] Утрата разрешения приводит к повторному выбору, не к зависанию.
- [ ] Основной offline сценарий не требует network entitlement.

## Проверка

Sandboxed Release: open/import/export/backup в выбранной внешней папке и revoke access.
