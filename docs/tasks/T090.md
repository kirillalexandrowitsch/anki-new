## Область изменений

Предлагаемые файлы/модули: `Features/Common/Confirmations; Settings`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Reset settings действует только на выбранный раздел и не удаляет материал.
2. Denied notifications и file access показывают сохранённый выбор и конкретный путь исправления.
3. Повторно проверить typed collection confirmation, disabled state и backup-before-delete.

## Критерии готовности

- [ ] Все четыре состояния листа 42 воспроизводимы без настоящего удаления личных данных.
- [ ] Escape не выполняет действие и возвращает фокус.

## Проверка

Permission fixtures, empty/mismatch/exact confirmation, reset scope и Cancel.
