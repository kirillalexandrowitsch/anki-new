# T053 · Укрепить согласованность backup и медиа

## Результат

Закрыть реальные окна сбоя между БД, файлами и архивом.

## Зависимости

[T011](T011.md) · [T046](T046.md) · [T052](T052.md)

## Область изменений

Предлагаемые файлы/модули: `Infrastructure/Backup; Tests/FaultInjection`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Уточнить snapshot barrier и запрет media GC во время копирования.
2. Проверить hash manifest, retention только после успешной проверки и pinned backups.
3. Реализовать внешнее swap recovery и cleanup старых staging по безопасным правилам.

## Критерии готовности

- [ ] Каждая ссылка snapshot ведёт в присутствующий verified файл.
- [ ] После crash restore выбирается целая старая или целая новая коллекция.

## Проверка

Fault matrix по каждому checkpoint с concurrent read и недостатком места.
