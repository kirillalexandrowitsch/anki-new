## Область изменений

Предлагаемые файлы/модули: `Features/Export; Features/Decks`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Добавить filename, destination, format и include media/progress capabilities.
2. Показывать недоступность опций с объяснением и preview несовместимых данных.
3. Экспорт завершать success только после проверки final file; добавить Show in Finder.

## Критерии готовности

- [ ] CSV не обещает перенос прогресса.
- [ ] Cancel/ошибка destination не оставляет валидно названный неполный файл.

## Проверка

Матрица форматов/options, overwrite confirmation и отказ файловой системы.
