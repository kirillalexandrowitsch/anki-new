# T031 · Добавить дерево, сетку и перемещение колод

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M2. **Сложность:** M.

## Результат

Организовать вложенные колоды и альтернативные виды списка.

## Зависимости

[T013](T013.md) · [T030](T030.md)

## Область изменений

Предлагаемые файлы/модули: `Features/Decks; Core/UseCases/Decks`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Добавить parent/child query, disclosure, grid/list toggle и favorite filter.
2. Реализовать MoveDeck с проверкой циклов и собственного поддерева.
3. Сохранять выбранный вид/раскрытие как UI preferences, при пустом фильтре предлагать reset.

## Критерии готовности

- [ ] Нельзя создать цикл или переместить колоду в себя.
- [ ] Сетка и дерево показывают согласованные счётчики и избранное.

## Проверка

Дерево глубиной несколько уровней, move/undo при поддержке команды и пустой фильтр.
