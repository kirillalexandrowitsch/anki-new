# T027 · Сделать CSV и собственный экспорт данных

## Результат

Дать начальный перенос содержимого и родную точную копию.

## Зависимости

[T009](T009.md) · [T011](T011.md) · [T014](T014.md) · [T016](T016.md)

## Область изменений

Предлагаемые файлы/модули: `Infrastructure/ImportExport/`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Написать потоковый CSV/TSV parser с quoted multiline, Unicode и diagnostics.
2. Экспортировать согласованный CSV и versioned cardsdeck через save panel.
3. Разделить format capabilities: CSV без progress/media payload, точная backup-копия отдельным форматом.

## Критерии готовности

- [ ] Файл с кавычками и переносами не ломает строки.
- [ ] Собственные архивы не выдаются за APKG, неподдержанные опции неактивны.

## Проверка

Round trip текста, повреждённая кодировка, отмена панели и запись в недоступную папку.
