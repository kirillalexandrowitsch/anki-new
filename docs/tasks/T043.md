## Область изменений

Предлагаемые файлы/модули: `Features/Statistics/Details; Core/Queries/Stats`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Разделить success ratio и model retrievability с пояснениями.
2. Прогноз строить по текущим dueAt, сравнение периодов нормализовать по выбранной длине.
3. Построить годовой календарь с текстовыми подробностями дня и легендой.

## Критерии готовности

- [ ] Forecast явно обозначает допущения и не выдаёт будущие оценки за данные.
- [ ] Нулевой denominator отображается как отсутствие данных.

## Проверка

Проверка формул на ручном журнале и доступного текстового эквивалента графиков.
