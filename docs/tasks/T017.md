## Зависимости

[T003](T003.md) · [T005](T005.md) · [T012](T012.md)

## Область изменений

Предлагаемые файлы/модули: `Core/Study; Infrastructure/Scheduling/`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Оборачивать pinned FSRS-6 и переводить Grade/phase/parameter sets.
2. Зафиксировать точную таблицу переходов learning/relearning для шагов профиля; исключить двойное применение коротких шагов.
3. Сделать preview чистым, проверить now/seed, finite values и versioned snapshots.

## Критерии готовности

- [ ] Все четыре оценки на контрольных входах дают ожидаемые dueAt и memory state.
- [ ] Повтор вычисления с теми же параметрами воспроизводим; UI не задаёт интервалы.

## Проверка

Reference vectors для new/review/relearning, Same-day, Again и ошибочных параметров.
