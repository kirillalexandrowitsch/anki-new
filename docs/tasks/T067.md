# T067 · Принять доступность и локализацию основы

[Оглавление плана](../README.md) · [Все задачи](../TASKS.md) · [Порядок разработки](../ROADMAP.md)

**Статус:** запланировано. **Этап:** M3. **Сложность:** L.

## Результат

Сделать главные сценарии пригодными для клавиатуры и VoiceOver.

## Зависимости

[T044](T044.md) · [T047](T047.md) · [T048](T048.md) · [T049](T049.md) · [T050](T050.md) · [T052](T052.md)

## Область изменений

Предлагаемые файлы/модули: `CardsFeatures; Resources/Localizable.xcstrings`. Путь уточняется при создании исходников без изменения границ ответственности.

## Как выполнить

1. Пройти основной путь без мыши, назначить labels/values/states и объявления ошибок.
2. Проверить plural rules, интервалы и английскую локаль без обрезания строк.
3. Проверить контраст реальных цветов, большой текст и reduced motion; записать нерешённые defects.

## Критерии готовности

- [ ] Пользователь может создать и повторить Card клавиатурой.
- [ ] Ни ошибка, ни статистический статус не требуют различения только цвета.

## Проверка

Ручной VoiceOver и keyboard audit плюс targeted UI regression.
