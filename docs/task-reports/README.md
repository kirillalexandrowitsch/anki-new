# Отчёты задач

Создавать `Txxx.json` командой `python3 scripts/tasks.py init-report Txxx` из корня проекта. Поля criteria соответствуют карточке задачи; не менять их текст, чтобы обойти проверку. Проверки и evidence заполнять после выполнения, а не заранее.

Каждый завершённый отчёт включается в тот же commit, что код и статус задачи. Git хранит commit hash; записывать hash этого же commit внутрь самого отчёта не нужно. Ограничения, влияющие на обязательный критерий, означают незавершённую задачу, а не successful completion.
