# Бюджет: без дополнительных платежей

[Оглавление](README.md) · [Инструкции чатов](AI_WORKFLOW.md) · [Технические решения](DECISIONS.md)

Обязательное требование владельца от 18 октября 2026 года: **единственная планируемая трата — существующая подписка Codex**. Для разработки и использования этого личного приложения не требуются новые подписки, покупки, платные API и лицензии. Это ограничение действует на все 100 задач и последующие изменения.

## Как укладываемся

| Область | Решение без дополнительной оплаты |
|---|---|
| Редактирование | Имеющийся Codex, бесплатный VS Code; второй AI-помощник не требуется |
| Компилятор и SDK | Xcode/Swift и SDK Apple; платная Developer Program не нужна для личной разработки и локального тестирования |
| Код и история | Обычный Git и публичный репозиторий на GitHub Free; тариф Pro не требуется |
| Сборки и тесты | Локально и на стандартных бесплатных ubuntu-24.04/macOS-15 runners публичного GitHub; без larger runners и платного хранения |
| База данных | Локальная SQLite и GRDB; без сервера, managed database и облачного хранения |
| Повторение | Локальный FSRS-адаптер с проверенной бесплатной лицензией; без model inference API |
| Аудио | Локальные вложения и доступные установленные системные голоса; без платного TTS/распознавания |
| Переводы и контент | Ввод вручную или собственный разрешённый материал; без платного перевода и словарного API |
| Интерфейс | Системные контролы/шрифты и доступные системные символы; без платных UI-kit и ассетов |
| Копии | Локальные файлы и уже имеющиеся носители; покупка облачного backup не требуется |
| Установка | Локальная Release `.app`, локальная подпись при необходимости; без обязательного Developer ID, notarization и App Store |

Apple указывает, что для начала разработки и тестирования на личных устройствах членство в программе не требуется. GitHub Free поддерживает приватные репозитории; отдельные metered-продукты имеют свои лимиты и оплату. Владелец подтвердил публичность: используем бесплатные стандартные public runners, без larger runners, artifact/cache uploads и платных продуктов. При возвращении в private hosted jobs автоматически не запускаются. [Apple](https://developer.apple.com/help/account/membership/programs-overview), [GitHub Free](https://docs.github.com/en/get-started/learning-about-github/githubs-plans).

## Правила изменения проекта

1. Перед добавлением пакета проверить его лицензию, необходимость оплаты, ограничение личного/некоммерческого использования и транзитивные зависимости. Бесплатный доступ на пробный период не подходит.
2. Не регистрировать платёжные реквизиты, не включать trial, upgrade или usage billing. Не менять уже существующие подписки пользователя.
3. Для GitHub разрешены только стандартные public runners ubuntu-24.04/macOS-15. Не использовать larger runners, Actions в private, Codespaces, Packages, Git LFS и uploads artifacts/cache. Большие личные коллекции и сборки в Git не добавлять; исходные PNG дизайна уже хранятся обычным Git.
4. В приложении нет платного AI API. Использование Codex для написания кода не требует встраивать Codex/OpenAI API в готовое приложение. Отдельные API-ключи для основного сценария не нужны.
5. При ограничении доступа Codex сохранить файлы и историю; не покупать дополнительные credits. Этот проект не обещает безлимитную работу подписки и не требует доплат за продолжение.
6. Если бесплатный вариант не поддерживает предложенную функцию, описать ограничение и пересмотреть её техническую реализацию. Самостоятельно создавать обязательный платный шаг запрещено.

## Приёмка

T003 фиксирует бесплатные зависимости, T012 — check script и его запуск в бесплатном CI, T095 проверяет лицензионный и финансовый состав, T096 — локальную установку без платной программы. Новый чат читает это ограничение через корневой AGENTS.md. Отчёт задачи должен явно отметить найденную зависимость от оплаты; такая зависимость блокирует её принятие до бесплатной замены или явного изменения требования самим владельцем.
