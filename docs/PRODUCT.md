# Продукт и объём

[Оглавление](README.md) · [Архитектура](ARCHITECTURE.md) · [Задачи](TASKS.md)

## Для кого и для чего

«Карточки» — личное приложение владельца проекта для изучения английского на своём MacBook с Apple Silicon. Пользователь собирает слова и примеры в колоды, повторяет материал по расписанию, слушает произношение и видит историю своей работы. Основной сценарий должен работать без интернета: открыть приложение → увидеть задания → пройти занятие → получить актуальную статистику. Публичное распространение не планируется.

Интерфейс нативный: системное окно macOS, боковая панель, меню, сочетания клавиш, Open/Save-панели, светлая и тёмная темы. Визуальная система берётся из [DESIGN.md](../design-references/DESIGN.md), но элементы реализуются как настоящие контролы, а не как изображения экранов.

## Пять основных разделов

| Раздел | Назначение | Основные данные и действия |
|---|---|---|
| Сегодня | Начало занятия и текущая нагрузка | Новые/ожидающие карточки, продолжение занятия, слово дня, поиск, локальные уведомления |
| Колоды | Организация материала | Дерево и сетка, создание, вложенность, перемещение, избранное, свойства, начало занятия, экспорт |
| Статистика | История и нагрузка | Количество оценок, время, календарь, фильтры, прогноз, запоминание с понятным определением |
| Библиотека | Просмотр и изменение карточек | Поиск, фильтры, таблица, редактор, теги, история, массовые действия, импорт |
| Настройки | Предпочтения и обслуживание | Основные / Повторение / Карточки / Данные; горячие клавиши — диалог внутри Основные |

Занятие, редактор, мастер импорта и менеджеры расширенных функций открываются из этих разделов. Дополнительных обязательных пунктов главной навигации не появляется.

## Базовые правила поведения

- Ответ скрыт: основное действие «Показать ответ», клавиша Пробел. Допустимы звук и пропуск. Оценок до раскрытия нет.
- Ответ открыт: Снова / Трудно / Хорошо / Легко, клавиши 1–4. После оценки следующая карточка снова скрыта. Проверка введённого слова показывается после того же раскрытия, а не автоматически оценивает память.
- Изменения карточки сохраняются явно. Настройки сохраняются автоматически после проверки допустимости. Временные изменения внутри диалога применяются его кнопкой подтверждения.
- Отмена/Escape закрывает диалог без применения черновика. Несохранённый редактор требует выбора Сохранить / Не сохранять / Отмена.
- Опасные операции объясняют последствия и требуют подтверждения. Удаление карточки допускает отмену 5 секунд. Полный сброс коллекции отдельно защищён вводом её имени.
- Ошибка диска, импорта или аудио должна оставлять понятное следующее действие и не выдавать неуспешную операцию за успешную.

## Последовательные результаты

| Результат | Что пользователь уже сможет делать | Что ещё предстоит |
|---|---|---|
| M0 — фундамент | Запуск технической оболочки на arm64, готовое хранилище и тестовые данные | Пользовательский сквозной сценарий |
| M1 — рабочая вертикаль | Создать простую колоду и карточку, повторить, закрыть и открыть приложение, увидеть историю; CSV и собственная копия данных | Полный UI основного набора и совместимость APKG |
| M2 — основные экраны | Работа с вложенностью, тегами, видами карточек, библиотекой, настройками и аналитикой по листам 01–24 | Укрепление файловых операций и APKG |
| M3 — основная бета | Проверенная сохранность данных, задокументированная совместимость APKG, доступность основных сценариев | Расширенные функции листов 25–42 |
| M4 — расширенный проект | Менеджеры типов, коллекций, шаблонов, сложный поиск, запись звука, текстовые заготовки, дополнительные разрезы статистики | Итоговая проверка и выпуск |
| M5 — личная установка | Release `.app` на ноутбуке владельца, проверка обновления и восстановления, инструкция пересборки | Последующие личные улучшения |

M1 — версия для проверки основного сценария, а не обещание реализовать весь дизайн быстро. M3 закрывает исходные листы 01–24; M4 включает предложения листов 25–42. Полный план учитывает обе группы, но позволяет получать рабочее приложение до завершения всех расширений.

## Что не входит автоматически

Облачная синхронизация, аккаунты, платежи, маркетплейс колод, сервер переводов, AI-генерация, автоматическая оценка произношения, мобильное приложение, Intel-сборка и расширения сторонним кодом не входят в исходный объём. Для них понадобятся новые решения и задачи. Свой формат резервной копии не называется `.apkg`.

Совместимость с Anki определяется поддерживаемыми форматами и тестовыми файлами, а не визуальным сходством. Не все произвольные HTML/JavaScript-шаблоны или расписания Anki обязаны конвертироваться без потерь: ограничения должны быть видны до импорта.

## Термины и числа

**Запись (Note)** — слово, перевод, примеры и вложения. **Карточка (Card)** — направление/вариант проверки этой записи с собственным расписанием. Одна запись может дать две карточки в прямом/обратном направлении или несколько карточек с пропусками. «Карточки» в счётчиках означают Card; «словарные записи» — Note. Редактор показывает, что общие поля затрагивают все связанные карточки.

Сессия — последовательность учебных действий. Оценка — одно подтверждённое событие повторения; одна карточка может получить несколько оценок за день. Процент успешных ответов и модельная вероятность воспоминания — разные метрики, они должны иметь разные подписи. Демо-данные создаются только по выбору пользователя и отделяются от измерений реального использования.

## Первый запуск (T024)

В пустой коллекции «Сегодня» показывает welcome с созданием первой колоды. «Пока
пропустить», Cancel и Escape оставляют пустое состояние без записи черновика;
после перезапуска незавершённый welcome можно пройти заново. Боковая навигация
остаётся доступной. Уже использованные коллекции (включая удалённые колоды) не
получают welcome и наполнение автоматически.

В коротком диалоге требуется название. По умолчанию создаётся пустая колода;
только включённый выбор «Добавить три демо-карточки» создаёт Hello / Привет,
Thank you / Спасибо, Good morning / Доброе утро (Basic, английский → русский).
Записи имеют тег «Демо», оценки и время не подставляются. После явного занятия
обычные ReviewLog учитываются так же, как для других карточек. Язык здесь —
подпись фиксированного демо, не настройка будущих типов карточек.

Успех показывает первую колоду и, для демо, три записи; Start и счётчики берутся
из реального Today/QueueBuilder. Пустая колода предлагает добавить карточки в
библиотеке. Импорт виден, отключён и объяснён до подключения мастера T051;
кнопка не открывает файловый диалог и не создаёт скрытую колоду. T051 должна
подключить отдельный маршрут мастера, сохранив атомарность его применения.

Создание колоды, необязательных Notes/Cards/schedules и completion
`collection_settings[onboarding.v1]` выполняется одной транзакцией writer.
Повтор команды/новая попытка из другого окна возвращает сохранённый результат;
сбой на любом шаге откатывает весь набор. Во время commit отмена недоступна.
После завершения и повторного запуска демо не добавляется заново. Существующие
миграции не меняются, completion входит в обычную резервную копию SQLite.
