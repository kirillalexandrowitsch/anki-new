# План разработки «Карточки»

Документация от 18 октября 2026 года для нативного приложения macOS на MacBook с Apple Silicon. Основание — [каталог дизайн-проекта](../design-references/index.html): 6 базовых экранов, 42 листа, 168 панелей. Приложение пока не реализовано; ниже зафиксирован предлагаемый технический проект.

## Как начать

Начать с **[T001 — окружение разработки](tasks/T001.md)**. Затем идти по зависимостям из реестра; первая рабочая сквозная версия заканчивается T030. Полный основной набор дизайна принимается на T068, расширения — на T092, личная установка и завершение — на T100. Приложение предназначено только для ноутбука владельца; публичная публикация и платные сертификаты не требуются планом.

Каждая задача содержит цель, зависимости, область изменений, шаги реализации, критерии готовности и проверку. Актуальные статусы — в [PROJECT_STATUS.md](PROJECT_STATUS.md); источник — [backlog.json](backlog.json). Обновлять их через `python3 scripts/tasks.py`. Завершённая документация не означает завершённую реализацию. 100 задач покрывают текущий согласованный объём; обнаруженные ошибки и изменения могут добавить новые задачи без перенумерации существующих.

Принятые для планирования предположения: macOS 15+, архитектура arm64, русский интерфейс с английской локализацией, локальные данные, одна активно открытая коллекция, без сервера и обязательной регистрации. Это продуктовые решения, которые можно поменять до реализации соответствующих задач; их изменение требует обновить связанные документы и критерии.

При расхождениях приоритет имеют явные требования пользователя, затем согласованные правила [FLOWS.md](../design-references/FLOWS.md), затем этот технический проект, затем подписи в растровых макетах. Новые технические решения не превращают иллюстративную статистику и интервалы в проверенные учебные данные.
