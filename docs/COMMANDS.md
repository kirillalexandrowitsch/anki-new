# Главные команды T026

[Архитектура](ARCHITECTURE.md) · [Занятие](STUDY_SESSION.md)

`AppCommandID` задаёт стабильные идентификаторы UI-действий; они не заменяют UUID
транзакций Core. `AppCommandContext` проверяет доступность при построении меню и
повторно при вызове. `AppShellView` передаёт один контекст своим кнопкам через
Environment и меню через focused scene value. Каждое окно хранит собственную
навигацию; окно настроек не получает команды коллекции из фонового окна.

| Действие | Сочетание | Доступность |
|---|---|---|
| Сегодня / Колоды / Статистика / Библиотека | ⌘1 / ⌘2 / ⌘3 / ⌘4 | Главное окно без открытого диалога |
| Новая карточка | ⌘N | Загружена рабочая область редактора |
| Новая колода | ⇧⌘N | Загружена рабочая область колод |
| Редактировать карточку | ⌘E | Библиотека с выбранной карточкой, чтение завершено |
| Импортировать | ⇧⌘I | Отключено до появления настоящего сервиса импорта |
| Настройки | ⌘, | Вне диалога; та же нативная Settings-сцена, что у кнопки в sidebar |
| Начать занятие | Меню «Занятие» / кнопка Сегодня | Доступная очередь или восстановимая сессия |

Создание карточки/колоды из другого раздела сначала выбирает соответствующий раздел,
затем открывает тот же редактор. Открытый редактор, onboarding, загрузка занятия и
само занятие отключают команды родительского окна. Сохранение редактора остаётся
явным; Escape/Cancel не применяет draft. Если колод ещё нет, редактор карточки
объясняет необходимость создать колоду и не позволяет Save.

Study передаёт отдельный focused context. «Показать ответ» и четыре оценки вызывают
те же действия из меню, кнопок и клавиш. До reveal доступны только reveal и прежние
skip/audio; оценки в меню отключены и на экране отсутствуют. Пауза, подтверждение
выхода, pending write, ошибка checkpoint и остановленная сессия учитываются автоматом.
Оценка синхронно переводит автомат в committing до постановки async записи, поэтому
повторный ввод не создаёт вторую команду.

У Space/1–4 нет глобального menu key equivalent: `StudyKeyRouter` принимает их только
без модификаторов/повтора, в своём key window, вне `NSTextInputClient` и без attached
sheet. Текстовые поля и системные панели получают исходное событие. Явный выбор пункта
меню разрешён независимо от текстового responder, если автомат допускает действие.
⌘W использует прежнее подтверждение выхода. Настройка сочетаний остаётся задачей T047.
