# Базовая библиотека T016

[Архитектура](ARCHITECTURE.md) · [Контракт запросов](QUERIES.md)

Библиотека показывает строки Card из generation-scoped query snapshots, по 100 на страницу.
Счётчики «Карточек» и «Записей» берутся из одного snapshot и относятся к текущему поиску.
Направление Basic — «Лицевая → оборотная»; для других вариантов показывается stable variant key.
Нативный выбор строки и доступное действие на её слове выбирают одну и ту же Card.
Стабильный CardID сохраняет выбор при обновлении или изменении порядка строк на странице.
Если выбранная Card исчезла со страницы, выбирается первая доступная; смена поиска/страницы
сбрасывает выбор. Пустая последняя страница после изменения данных возвращается на предыдущую.

Поиск ищет буквальные префиксы в front/back/examples по контракту T010, максимум 512 символов.
Пустая коллекция предлагает добавление карточки; если колод ещё нет, редактор объясняет,
что сначала нужна колода. Пустой результат поиска предлагает очистить поиск.
Импорт, расширенные фильтры и массовые действия реализуются отдельными задачами.

Инспектор читает полное сохранённое содержимое Note через Core repository, обновляется при
смене выбора/revision и отвергает поздние ответы предыдущей строки/коллекции. Показывает
текст, транскрипцию, примеры, теги и количество вложений; проигрывание и просмотр медиа
относятся к следующим задачам. В узком окне инспектор открывается кнопкой; Edit остаётся доступным.
Add/Edit открывают прежний защищённый редактор с явным Save. Закрытие sheet не вызывает
перезагрузку: наблюдение само получает сохранённые изменения, включая Save из другого окна.
Ошибка чтения имеет действие повтора; отмена экрана/закрытие коллекции останавливают наблюдение.

## Удаление выбранной Card (T029)

Инспектор и контекстное меню одной строки открывают подтверждение с актуальными Card/Note
revision, словом, вариантом и числом других активных Card связанной Note. Удаляется только
выбранная Card. Note, её поля, теги, медиа, расписание и история сохраняются; другие варианты
не затрагиваются. Cancel/Escape не записывает ничего. Если Card/Note или область изменились,
commit отклоняется и диалог предлагает заново загрузить подтверждение.

Одна writer transaction выставляет `deletedAt`, `generationState=suppressed`, увеличивает
Card revision, записывает `deletion_batches` (`kind=card.v1`), domain event и command receipt.
Library/Today/QueueBuilder исключают tombstone после commit; старую открытую карточку нельзя
оценить. Save Note не регенерирует существующий suppressed вариант, включая Save старого draft.
Undo возвращает активную Card с новой revision, не переписывая ни расписание, ни новые поля Note.
Ошибки сохраняют commandID для безопасного retry; повтор уже записанной команды не дублирует эффект.

Уведомления с Undo находятся внизу главного окна, доступны с любой вкладки и показывают остаток
5 секунд. Сервис проверяет deadline внутри транзакции, независимо от UI heartbeat. В batch
сохраняются boot UUID и `mach_continuous_time` (включает sleep): wall-clock/timezone не продлевают
окно. Перезапуск приложения в том же boot сохраняет только оставшийся срок, повторное открытие
не даёт ещё 5 секунд. После reboot или отката monotonic значения Undo закрыто. Tombstone сохраняется.

`undoUntil` — wall-time metadata, не источник разрешения Undo; `purgeAfter` — нижняя граница
отложенной очистки (7 дней), не обещание немедленного уничтожения. T029 физически ничего не
удаляет: уникальный suppressed вариант остаётся защитой от повторной генерации. GC/оптимизация
из T085 обязана учитывать batch/операции и ссылки Note; media активного Undo всегда сохраняется.
Это не пользовательская корзина. Миграция и новые зависимости не нужны.
