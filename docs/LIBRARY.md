# Базовая библиотека T016

[Архитектура](ARCHITECTURE.md) · [Контракт запросов](QUERIES.md)

Библиотека показывает строки Card из generation-scoped query snapshots, по 100 на страницу.
Счётчики «Карточек» и «Записей» берутся из одного snapshot и относятся к текущему поиску.
Направление Basic — «Лицевая → оборотная»; для других вариантов показывается stable variant key.
Нативный выбор строки и доступное действие на её слове выбирают одну и ту же Card.
Стабильный CardID сохраняет выбор при обновлении или изменении порядка строк на странице.
Если выбранная Card исчезла со страницы, выбирается первая доступная; смена поиска/страницы
сбрасывает выбор. Пустая последняя страница после изменения данных возвращается на предыдущую.

Поиск ищет буквальные префиксы в front/back/examples по контракту T010, максимум 512 символов.
Пустая коллекция предлагает добавление карточки; если колод ещё нет, редактор объясняет,
что сначала нужна колода. Пустой результат поиска предлагает очистить поиск.
Импорт, расширенные фильтры и массовые действия реализуются отдельными задачами.

Инспектор читает полное сохранённое содержимое Note через Core repository, обновляется при
смене выбора/revision и отвергает поздние ответы предыдущей строки/коллекции. Показывает
текст, транскрипцию, примеры, теги и количество вложений; проигрывание и просмотр медиа
относятся к следующим задачам. В узком окне инспектор открывается кнопкой; Edit остаётся доступным.
Add/Edit открывают прежний защищённый редактор с явным Save. Закрытие sheet не вызывает
перезагрузку: наблюдение само получает сохранённые изменения, включая Save из другого окна.
Ошибка чтения имеет действие повтора; отмена экрана/закрытие коллекции останавливают наблюдение.
