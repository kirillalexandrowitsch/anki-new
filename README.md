# Anki New · Карточки

Проект нативного приложения macOS для изучения английского на MacBook с Apple Silicon.

- [Дизайн-каталог](design-references/index.html) — 6 экранов и 42 листа с 168 состояниями.
- [Технический проект и начало разработки](docs/README.md) — стек, архитектура, данные и поведение.
- [Архитектура приложения](docs/ARCHITECTURE.md).
- [Сборка и запуск каркаса приложения](docs/APP_SCAFFOLD.md).
- [Порядок разработки](docs/ROADMAP.md) и [100 задач](docs/TASKS.md).
- [Первая задача: окружение Xcode](docs/tasks/T001.md).
- [Связь каждого состояния дизайна с реализацией](docs/TRACEABILITY.md).
- [Текущее состояние проекта](docs/PROJECT_STATUS.md) и [работа через отдельные чаты Codex](docs/AI_WORKFLOW.md).

Предлагаемый стек: Swift 6, SwiftUI + AppKit, SQLite через GRDB, FSRS-6, Swift Charts и системные сервисы macOS. Целевая первая платформа: macOS 15+, arm64, локальная работа без обязательного сервера.

Это личное приложение для ноутбука владельца. Создан начальный Xcode-проект с четырьмя модулями локального Swift package, навигацией, Settings scene и тестами. Экраны пока показывают заглушки; хранилище и учебные сценарии реализуются в следующих задачах. Статусы хранятся в `docs/backlog.json`; `AGENTS.md` задаёт правила для нового чата. Публичная публикация и платная подпись не требуются.

**Бюджет: никаких дополнительных платежей сверх имеющейся подписки Codex.** Инструменты/зависимости бесплатные, сборки и тесты локальные либо на стандартных бесплатных public runners. [Политика бюджета](docs/BUDGET.md).

Разработка идёт через `task/Txxx → dev → stage → main` с обязательным зелёным CI. [Автономный процесс](docs/AUTOMATION.md).
